# Addis Market Order Summary

## Exercise

Created an order summary using:

* `map()`
* `filter()`
* `reduce()`
* Destructuring
* Spread operator
* ES Modules

## Files

* `orders.js` – sample orders
* `pricing.js` – pricing functions
* `summary.js` – calculates and displays the summary

## Run

```bash
node js/summary.js
```
