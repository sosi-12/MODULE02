# Habesha Eatery - Landing Page

A responsive landing page built with HTML and CSS using Grid and Flexbox layouts.

## Features
- **Navbar:** Sticky Flexbox header with logo and navigation links.
- **Menu Grid:** Built with CSS Grid (`auto-fit`) to adapt to screen sizes.
- **Flexbox Cards:** Card components with prices pinned to the bottom.
- **Popular Badge:** Absolutely positioned badge on highlighted menu items.

## How to Run
Open `index.html` in any web browser or use VS Code's Live Server.
