# Day 17 — Higher-Order Functions

## Class Exercise: Habesha Eatery Order Module

This exercise demonstrates higher-order functions, callbacks, arrow functions, rest parameters, reduce, closures, and CommonJS modules.

### What the program does

- Calculates the subtotal of order items.
- Applies a 10% member discount.
- Adds 15% VAT.
- Formats the final price in ETB.
- Generates receipt numbers using a closure.
