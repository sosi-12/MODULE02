# Addis Market Shopping List

## Project Goal
A single-page grocery shopping list built with JavaScript DOM and Events using the state-then-render approach.

## Features
- Add grocery items
- Mark items as bought
- Remove items
- Live item counter
- Uses `data-id` and event delegation
- Uses `.done` CSS class for bought items
